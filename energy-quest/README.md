# חדר הבקרה של האנרגיה ⚡

משחק מדעים בעברית לכיתה ו׳, המיועד להכנה למבחן בנושא **ייצור חשמל והמרות אנרגיה**.

משחקים ב־[גרסה המקוונת](https://gilweiss83-crypto.github.io/english-word-journey/energy-quest/) או פותחים את `index.html` בדפדפן. אין צורך בהתקנה.

## מה לומדים

- רוח: אנרגיית תנועה → סיבוב טורבינה → מחולל → חשמל.
- תחנה הידרואלקטרית: תנועת מים → סיבוב טורבינה → מחולל → חשמל.
- תחנה תרמית: אנרגיה כימית בדלק → חום → קיטור בתנועה → טורבינה → מחולל → חשמל.
- טורבינת גז: שרפה וחום → גזי שרפה בתנועה → טורבינה → מחולל → חשמל.
- ההבדל בין טורבינה, שמסתובבת, לבין מחולל שממיר את הסיבוב לאנרגיה חשמלית.
- קלט ופלט: חשמל כפלט הרצוי, לצד פלטים בלתי רצויים אפשריים כמו רעש, שינוי סביבתי וגזי פליטה.

## איך המשחק מלמד

המשחק בנוי להבנה ולא לשינון:

1. ארבעה גיפים קצרים מציגים את התנועה בכל שיטת ייצור.
2. מעבדה אינטראקטיבית מדגימה קשר של סיבה ותוצאה בין עוצמת הזרימה, מהירות הטורבינה והפקת החשמל.
3. בונים לבד ארבע שרשראות אנרגיה מחלקים מעורבבים.
4. מבחן הבנה כולל תקלות, השוואות ושאלות "מה יקרה אם" עם הסבר לאחר כל תשובה.
5. טעויות נשמרות לסבב תרגול ממוקד, והשיא נשמר בדפדפן המקומי.

החתולים והכלב מצוות האנרגיה מלווים את כל שלבי המשחק. המשחק מותאם למחשב ולטלפון, כולל ניווט מקלדת, טקסט חלופי ומשוב נגיש.

## קבצים

- `index.html` — המשחק המלא, ללא תלויות חיצוניות.
- `energy-crew.webp` — איור הדמויות.
- `assets/*.gif` — ארבע המחשות מונפשות של ייצור החשמל.
