# מסע המילים — משחק אנגלית לכיתה ו׳

משחק דפדפן עצמאי לתרגול אוצר המילים של Unit Check, Parts 1–5.

## הפעלה

פותחים את `index.html` בדפדפן. אין צורך בהתקנה או בשרת.

## מה יש במשחק

- כרטיסיות עם הקראת מילים
- תרגול אנגלית לעברית ולעברית לאנגלית
- זיהוי מילים בהאזנה
- כתיבת מילים באנגלית
- התאמת זוגות ומשחק זיכרון
- אתגר של 10 שאלות
- בחירת חלקים 1–3, חלקים 4–5 או כל הרשימה
- שמירת התקדמות מקומית בדפדפן

העיצוב והמבנה שואבים השראה ממשחק הדוגמה שסופק, עם תוכן ועיצוב מקוריים.
